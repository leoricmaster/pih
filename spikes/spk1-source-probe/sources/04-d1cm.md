## 摸底记录

| 字段 | 内容 |
|---|---|
| 类型 | 列表页 HTML（新闻中心聚合页 + `/col/1000/<栏目>/` 栏目页） |
| 采集方式预判 | HTTP+解析；changedetection.io 备选 |
| robots 允许度 | `https://www.d1cm.com/robots.txt`（200，`text/plain`，实测全文 8 行）：`User-agent: *` 下仅 `Disallow: /preview/`、`/images/`、`/include/`、`/js/`、`/css/`、`/templates/`——**资讯路径 `/col/`、文章页 `/YYYYMMDD….shtml` 均未禁止** → 允许。注意 robots 仅在 www 子域；news 子域无独立 robots.txt（访问即返回列表页软 200），沿用主域口径 |
| 反爬观察 | 无登录墙（详情正文匿名可读，实测 78KB 详情页含全文）；无验证码；无频控触发；SSR HTML（首页 1MB、新闻中心 311KB，链接全部内联）。陷阱：站点对不存在路径返回 HTTP 200 + `<title>404-页面未找到</title>` 软 404（实测 `/list/index_2.shtml`、`/col/1000/qydt/2/` 等），判存在性必须看标题/内容而非状态码 |
| 更新频率预估 | 日更（新闻中心首页含 2026-08-25 日期 8 处；企业动态栏目第 1 页最新条目 2026082x，第 2 页到 20260821） |
| 历史内容可达性 | 部分可达：栏目分页格式为 `/col/1000/<栏目>/index_<N>.shtml`，实测 qydt（企业动态）index_2 有效（62 条，38 条为新，日期 20260821）；index_5（20260820）、index_10（20260813）有效；index_20/30 返回软 404 → 企业动态约 10~19 页、覆盖约 2–4 周，**回溯 ≥3 个月未确认**（首页混有 2024-10/2024-12 旧文链接，但稳定回溯路径未确认）。文章 URL 含日期前缀 `/20260825191918.shtml`，历史文章直链可达（如首页可见 2024-10-18 文章链接） |
| 纸面结论 | 需适配（结构可解析；软 404 + 栏目翻页深度有限，增量采集可行、历史回填受限） |
| 实抓候选 | 是。理由：① robots 对目标路径无禁止；② SSR 无反爬；③ 作为"列表页 HTML 解析"最典型样本（比徐工简单）；④ 实抓验证栏目翻页真实深度与软 404 判定逻辑 |
