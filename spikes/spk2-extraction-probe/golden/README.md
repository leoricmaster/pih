## 字段口径（需求 §4.4）

| 字段 | 口径 | 示例 |
|---|---|---|
| `主体` | 公司 + 产品线；无明确公司主体的政策/数据类填发文或统计机构 | `"三一重工 SY375 遥控版"`、`"广州市人民政府"` |
| `事件类型` | 11 选 1（下方枚举），拿不准选 `其他` | `"新品发布"` |
| `事实描述` | 只写客观陈述，含量化参数原文；不夹带评价 | `"最高升降高度 2.5 米，液压驱动三联机构"` |
| `推断与判断` | 主观判断必须带 `"依据：……"`；无推断可留空 | `"改装面向存量机后市场（依据：面向已售机型改装宣传）"` |
| `标签` | 取自附件 A 初始标签树（下方词表），可多选；无相关标签给 `[]` | `["电动化", "远程遥控"]` |
| `量化参数` | 键值对，键用中文短语、值保留原文单位；无则 `{}` | `{"遥控距离": "1km"}` |

**标签词表**（附件 A 初始标签树）：

- 一级：`无人化作业`、`远程遥控`、`3D 引导与机控`、`电动化`、`智能辅助施工`

## 标注注意事项（基于 25 条样本实测形态）

1. **正文混有噪声**：三一样本带整段产品目录样板、d1cm 样本尾部混入评论区问答、khl 样本开头是 cookie 横幅、ccma 样本尾部是"相关资讯"链接列表——金答案只标**正文主体事件**，忽略噪声。
2. **khl 为英文源**：金答案各字段仍写中文（主体保留公司英文名可对照中文，如 `"斗山山猫（Doosan Bobcat）"`）。
3. **行业统计/数据快报**（S01/S03/S04/S05 销量/进出口/指数快报）：事件类型 `行业统计`，量化参数是重点（销量/同比）。
4. **政策法规**（S02 禁用高排放非道路移动机械区域）：事件类型 `标准动态`，主体填发文政府。
5. **财报/财经分析**（S07/S09/S10/S17 企业财报与股评期货行情）：事件类型 `财报`，量化参数重点（营收/销量/降幅）。
6. **行业合作**（S14 企业间合作、S22/S23/S24 政企调研、S25 校企）：事件类型 `行业合作`；**不含**服务营(S08)/抢修纪实(S11)/叉车节(S12)/治沙植树(S13)，这些仍归 `其他`。
7. **应用案例/项目落地**（S15 搅拌站助力高速项目）：若含供货/中标事实可标 `中标落地`，仅品牌宣传则 `其他`。
