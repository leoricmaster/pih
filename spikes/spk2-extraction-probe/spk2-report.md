# SPK-2 LLM 抽取准确率摸底报告

- 日期：2026-08-25
- 模型：MiniMax-M3（商业 API，OpenAI 兼容端点）
- 样本：25 条金答案集（spk2-extraction-probe/golden/golden.jsonl）
- 提示词迭代轮次：v1 / v2 / v3（3 轮）

## 结论

MiniMax-M3 在 25 条工程机械情报样本上，事件类型枚举命中率达 56%（v1 峰值），但字段级严格相等准确率仅 24.7%–31.1%（3 轮均 <80% 阈值）。核心瓶颈不在模型语义理解，而在自由文本字段（事实描述/推断与判断）的归一化字符串相等评分口径——模型语义正确但措辞改写即判"错误"。结论：LLM 抽取可用但需（1）结构化字段（枚举/标签）为主、自由文本为辅；（2）评分改用语义相似度或子串包含；（3）生产提示词需 few-shot 锚定金答案风格。

## 逐字段混淆分析

### 事件类型（枚举命中率 v1=56% / v3=52%）

11 类枚举中 7 类有金答案覆盖。主要混淆：
- **中标落地 → 其他**（2 条）：模型将获奖/项目落地归为"其他"，边界需 few-shot 澄清。
- **财报 → 其他**（2 条）：期货市场行情被模型判为非企业财报，枚举定义需明确"商品行情是否归财报"。
- **行业合作 → 其他**（2 条）：调研/会见类被归"其他"。
- **功能迭代 ↔ 新品发布**（各 1 条）：产品升级与发布的边界模糊。

### 主体（正确率 v3=9/23 ≈ 39%）

主要错误模式：**模型写公司全称而金答案为"公司+产品线"**。
- S06: G="山东铭德智能装备科技 升降驾驶室改装" / P="山东铭德智能装备科技股份有限公司"
- S15: G="方圆集团 HZS120型箱式搅拌站" / P="方圆集团"
- S19: G="Webuild 新热那亚圣乔治大桥项目" / P="RINA"（主体识别错误）

### 事实描述（正确率 0/23 — 最差字段）

**全部判"错误"**：模型摘录的数字与金答案一致（数字覆盖率 >90%），但措辞、标点、句序不同即判错。
- S01: G="据海关数据，2026年7月…63.93亿美元…同比增16.2%…" / P="2026年7月…63.93亿美元…同比增长16.2%…"（"增" vs "增长"，分号 vs 逗号）
- 根因：`_norm` 归一化只去空白+小写，标点与同义词差异即判错。

### 推断与判断（正确率 0/23）

同事实描述根因——模型生成的推断语义正确但措辞不同。
- S01: G="依据：1-7月出口同比增21.2%而进口同比降8.62%，反映出口走强、内需疲弱" / P="依据：出口高速增长、进口持续下降，行业出口竞争力增强"（语义等价，字符串不等）

### 标签（正确率 v3=6/15 ≈ 40%）

- v1 用"场景（矿山·港口·市政）"合并词，金答案用"场景-矿山"拆分词 → 全错。
- v2/v3 对齐标签树后正确率提升（3→6）。
- 剩余错误：模型多选标签（金答案 1 个，模型选 2-3 个），Jaccard <0.5。

### 量化参数（正确率 v3=7/23 ≈ 30%）

- 根因：key 命名不一致（G="7月进出口额" / P="7月贸易额"；G="营收同比" / P="营收同比增长"）。
- v2/v3 提示词要求短 key 后改善有限（5→7→7），模型倾向加年份前缀/后缀。
- 模型抽取的 value 数值与金答案一致率 >80%，问题仅在 key 命名。

## 典型错误案例（3 个）

### 案例 1：S01（行业统计）— 事实描述措辞改写致全字段判错

- 事件类型：正确（行业统计）
- 主体：正确（工程机械行业）
- 事实描述：**错误** — G 含"据海关数据"开头，P 直接从"2026年7月"开始；G 用逗号分隔，P 用分号；数字全部一致。
- 推断：**错误** — G="出口走强、内需疲弱"，P="出口竞争力增强"（语义等价）。
- 量化参数：**错误** — G keys=["7月进出口额","7月同比"]，P keys=["7月贸易额","7月贸易额同比"]（数值对、key 名不同）。

### 案例 2：S10（财报）— 主体识别偏差 + 量化参数 key 命名

- 主体：**错误** — G="碳酸锂期货市场" / P="碳酸锂行业"（金答案强调"期货市场"视角）。
- 事实描述：**错误** — 数字一致，措辞改写。
- 量化参数：**错误** — G keys=["7月31日收盘价","较上月同期"]，P keys=["主力合约收盘价","收盘价跌幅"]（同一数值不同 key）。

### 案例 3：S21（中标落地）— 事件类型误判 + 主体缺产品线

- 事件类型：**错误** — G="中标落地" / P="其他"（国家级科技奖项被归"其他"）。
- 主体：**错误** — G="三一汽车 矿山充填成套装备" / P="三一汽车制造有限公司"（缺产品线）。
- 事实描述：**错误** — G 聚焦获奖项目，P 扩写评选总数。
- 标签：正确（场景-矿山）。
